# manibo-site

家計簿アプリ ManiBo の利用規約・プライバシーポリシー・お知らせを置くリポジトリです。
GitHub Pages で https://tokiwagi-knot.github.io/manibo-site/ に公開しています。

| ファイル | 公開される URL | 中身 |
| --- | --- | --- |
| terms.md | /manibo-site/terms | 利用規約 |
| privacy.md | /manibo-site/privacy | プライバシーポリシー |
| notices.json | /manibo-site/notices.json | アプリが起動したときに読むお知らせ |
